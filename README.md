# Pizza-Order-WinForms
Pizza-Order-WinForms is a simple desktop application built with C# and Windows Forms. It allows users to select their favorite pizza, choose toppings, size, and crust type, and automatically calculate the total price.  
## Pizza Order System 🍕
A simple Windows Forms application built with C#.

### Features
- Choose pizza size
- Select toppings
- Real-time price calculation
- Order summary
- Images loaded from project resources

### Technologies
- C#
- Windows Forms (.NET)
- Visual Studio
